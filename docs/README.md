# Project website

Static site for the **Bipedal Robotic Locomotion with Reinforcement Learning** course project (Virginia Tech, Spring 2026).

## Files

- `index.html` — the page itself (plain HTML + CSS, no build step).
- `style.css` — styling.
- `assets/` — figures and the final-gait GIF.
- `paper.pdf` — *drop the compiled report here.*
- `slides.pdf` — *drop the presentation deck here.*

## Enable GitHub Pages

1. Push this repo to GitHub.
2. In **Settings → Pages**, set **Source = Deploy from a branch**, **Branch = `main` / `/docs`**, and save.
3. The site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
